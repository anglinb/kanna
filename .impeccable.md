## Design Context

### Users
Developers using Kanna to work with coding agents and manage their provider connections, models, and usage.

### Brand Personality
Quiet, compact, and direct. Settings should make the next action easy to find.

### Aesthetic Direction
Preserve Kanna's existing grouped settings rows, typography, semantic colors, and light and dark themes. The requested direction is to reduce clutter and keep related provider information together.

### Design Principles
- Show settings for connections the user has configured.
- Keep additional setup available through clear disclosure controls.
- Group account identity, usage, and defaults around the same provider.
- Adapt controls and usage labels to the width of their container.
- Preserve access through existing settings links and search.
